## 1. Visi Utama

Website ini bukan sekadar CV online, portfolio biasa, atau kumpulan project.

Website harus menjadi **demonstrasi langsung kemampuan teknologi**.

Prinsip utama:

> **Don't just tell. Demonstrate.**

Dan:

> **Every skill should become an experience.**

Artinya, ketika sebuah kemampuan ditampilkan, jangan hanya menuliskan bahwa kemampuan tersebut dikuasai. Sebisa mungkin website membuat pengunjung **mengalami, melihat, atau berinteraksi** dengan kemampuan tersebut.

Contoh:

- Web Development → website ini sendiri menjadi demonstrasi.
- UI/UX → user merasakan interface yang baik.
- 3D → user berinteraksi dengan objek 3D.
- Motion Design → scroll dan transition menjadi bagian dari storytelling.
- AI → ada intelligent interaction atau visualisasi AI.
- Computer Vision → konsep visual recognition ditampilkan secara interaktif.
- Data Analytics → data divisualisasikan dan dapat dieksplorasi.
- Data Science → data → model → prediction → insight divisualisasikan.
- Mobile Development → project ditampilkan melalui interactive device.
- Automation → workflow manual → automated system diperlihatkan.

Karena website menggunakan 3D dan motion:
